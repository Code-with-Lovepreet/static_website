# How to host a static website in AWS S3 bucket ?
## Description:
This project is a quick project that gives you simple steps how you can create an S3 bucket in AWS console and how to upload files to run static website.
    
                                        
**1.Search S3 in the spotlight search and then click on S3 once the option is visible.**
![s31](https://github.com/Code-with-Lovepreet/static_website/blob/main/images/1.png)
 
**2.Click on create bucket.**

 ![S32](https://github.com/Code-with-Lovepreet/static_website/blob/main/images/2.png)
 




**3. Select bucket type as a general purpose and give it a unique name. it will give you an error message if the name is already taken.**

![S33](https://github.com/Code-with-Lovepreet/static_website/blob/main/images/3.png)
![S34](https://github.com/Code-with-Lovepreet/static_website/blob/main/images/4.png)



 


**4.Enable network Access Control lists enable to give access to the AWS network to access this website publicly .** 

 ![S35](https://github.com/Code-with-Lovepreet/static_website/blob/main/images/5.png)

**5.  Uncheck the block so that website can be accessed publicly.**

![S36](https://github.com/Code-with-Lovepreet/static_website/blob/main/images/6.png)
![S37](https://github.com/Code-with-Lovepreet/static_website/blob/main/images/7.png)

 



**6. click on create bucket. For now, leave other settings as it is.**

   ![S38](https://github.com/Code-with-Lovepreet/static_website/blob/main/images/8.png)
   ![S39](https://github.com/Code-with-Lovepreet/static_website/blob/main/images/9.png )



**7. Bucket has been created.**

![S310](https://github.com/Code-with-Lovepreet/static_website/blob/main/images/10.png)


 


**8. Upload files in the bucket.**

![s311](https://github.com/Code-with-Lovepreet/static_website/blob/main/images/11.png)



**9. Make files publicly Accessible.**

![s312](https://github.com/Code-with-Lovepreet/static_website/blob/main/images/12.png)




**8.Go to permissions and enable static website.**

![s313](https://github.com/Code-with-Lovepreet/static_website/blob/main/images/13.png)


 







**9. Click on the website URL to Access it.**

![s314](https://github.com/Code-with-Lovepreet/static_website/blob/main/images/14.png)
